# @asif-sirajudeen/eds-ui

Earth Design System: shadcn base-nova components on Base UI, compiled by your Tailwind v4.

```bash
npm install @asif-sirajudeen/eds-ui
```

In your global CSS:

```css
@import "tailwindcss";
@import "@asif-sirajudeen/eds-ui/styles.css";
@import "@asif-sirajudeen/eds-ui/themes/default.css";
```

Browse components from the terminal with `npx eds-ui list`. Full docs: https://eds-ui.vercel.app
