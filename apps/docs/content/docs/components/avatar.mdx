## Local differences

None. The component matches upstream shadcn base-nova.

## Recipes

Avatar has no `status` prop and only `sm`, `default` and `lg` sizes. Both gaps are recipes, with no change to Avatar source.

### Status

Add an `AvatarBadge` with a color class: `bg-positive` for online, `bg-caution` for away.

### Extra sizes

Set the size by `className`, for example `className="size-16"`. `AvatarBadge` keeps the `default` size.
