## Local differences

None. The component matches upstream shadcn base-nova.

## TooltipProvider

Not required. Base UI Tooltip opens without a provider, and the stories and smoke test mount none. Mount `TooltipProvider` only to share a `delay` across tooltips; its default is `0`.
