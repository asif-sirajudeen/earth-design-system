```tsx
import { RadioGroup, RadioGroupItem } from "@asif-sirajudeen/eds-ui"
```

<RadioGroupExample />

```tsx
<RadioGroup defaultValue="a" aria-label="Plan">
  <Field orientation="horizontal">
    <RadioGroupItem value="a" id="doc-plan-a" />
    <FieldContent>
      <FieldLabel htmlFor="doc-plan-a">Starter</FieldLabel>
      <FieldDescription>For individuals.</FieldDescription>
    </FieldContent>
  </Field>
  <Field orientation="horizontal">
    <RadioGroupItem value="b" id="doc-plan-b" />
    <FieldContent>
      <FieldLabel htmlFor="doc-plan-b">Team</FieldLabel>
      <FieldDescription>For groups.</FieldDescription>
    </FieldContent>
  </Field>
</RadioGroup>
```

## Local differences

None. The component matches upstream shadcn base-nova.

## Recipes

RadioGroup has no label or description props. Wrap each `RadioGroupItem` in a `Field` with `FieldLabel` and `FieldDescription`, as in the example above. Name the group with `aria-label` or a `FieldSet` and `FieldLegend`.
