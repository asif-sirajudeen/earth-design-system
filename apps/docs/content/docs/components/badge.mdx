## Local differences

Badge adds two variants, `positive` and `caution`. They use the `--positive` and `--caution` theme colors. All other source matches upstream shadcn base-nova.

## Status mapping

| EDS status | Badge variant |
| --- | --- |
| info | `default` |
| critical | `destructive` |
| positive | `positive` |
| caution | `caution` |
