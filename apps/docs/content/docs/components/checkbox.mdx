```tsx
import { Checkbox } from "@asif-sirajudeen/eds-ui"
```

<CheckboxExample />

```tsx
<Field orientation="horizontal">
  <Checkbox id="doc-terms" />
  <FieldContent>
    <FieldLabel htmlFor="doc-terms">Accept terms</FieldLabel>
    <FieldDescription>You agree to our terms of service.</FieldDescription>
  </FieldContent>
</Field>
```

## Local differences

None. The component matches upstream shadcn base-nova.

## Recipes

Checkbox has no label or description props. Label it with `Field`, `FieldLabel` and `FieldDescription`, as in the example above. Without a visible label, set `aria-label`.
