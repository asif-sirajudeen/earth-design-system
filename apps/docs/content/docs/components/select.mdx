## Local differences

None. The component matches upstream shadcn base-nova.

## Recipes

Select has no `options` prop. Compose the list from parts: `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectGroup`, `SelectLabel`, `SelectItem` and `SelectSeparator`, as in the example above. Without a visible label, set `aria-label` on `SelectTrigger`.
